| **CryptoKitties**                                           | `0x06012c8cf97BEaD5deAe237070F9587f8E7A266d`                                                     | Ethereum   | Implements an early draft of ERC-721 rather than the final standard. It has ordinary `approve` and `transferFrom(address,address,uint256)`, but lacks the final safe-transfer/interface behaviour expected by many modern protocols. NFTX explicitly has a CryptoKitties branch instead of using its normal `safeTransferFrom` path. This usually requires a **legacy ERC-721 path**, although not a completely custom ownership API like CryptoPunks. ([GitHub][1])                                  |
| **MoonCatRescue**                                           | `0x60cd862c9C687A9dE49aecDC3A99b74A4fc54aB6`                                                     | Ethereum   | A genuinely custom pre-ERC-721 system. Cats are identified by five-byte IDs and transferred through an adoption-offer flow rather than ERC-721 `transferFrom`. The official ERC-721/ERC-998 wrapper is `0xc3f733ca98E0daD0386979Eb96fb1722A1A05E69`. The wrapped collection currently shows roughly **$73.3 million** of OpenSea volume. Native support requires a MoonCats-specific adapter; supporting only the official wrapper is considerably easier. ([MoonCatRescue][2])                       |
| **EtherRock**                                               | `0x41f28833Be34e6EDe3c58D1f597bef429861c4E2`                                                     | Ethereum   | Uses a bespoke owner/sale registry. Native transfers use functions such as `giftRock`, not ERC-721 transfers. The official ERC-721 wrapper is `0xA3F5998047579334607c47a6a2889BF87A17Fc02`; wrapping requires gifting the rock to the wrapper and then completing the wrapping operation. OpenSea currently shows roughly **$3.1 million** for the wrapped collection. ([etherrock.com][3])                                                                                                           |
| **PixelMap**                                                | `0x015A06a433353f8db634dF4eDdF0C109882A15AB`                                                     | Ethereum   | A custom 2016 tile registry, predating ERC-721. Ownership and sales are maintained through PixelMap-specific contract state and methods rather than the normal ERC-721 approval/transfer interface. The official ERC-721 wrapper is `0x050dc61dFB867E0fE3Cf2948362b6c0F3fAF790b`; the wrapped collection currently shows approximately **$10.3 million** of OpenSea volume. Native support would require a dedicated adapter, so wrapper-only support is preferable. ([pixelmap.io][4])               |
| **Curio Cards**                                             | **30 separate native contracts.** Example, Card #1: `0x6Aa2044C7A0f9e2758EdAE97247B03a0D7e73d6c` | Ethereum   | Each card type was issued through its own modified ERC-20 contract. Native ownership is therefore `(card contract, amount)`, rather than `(collection contract, tokenId)`. The official ERC-1155 wrapper is `0x73DA73EF3a6982109c4d5BDb0dB9dd3E3783f313`; its OpenSea collection currently shows approximately **$125.3 million** of volume. A marketplace can either implement ERC-20-edition custody for all 30 contracts or support only the wrapper. ([docs.curio.cards][5])                      |
| **Digital Zones of Immaterial Pictorial Sensibility — IKB** | `0x88AE96845e157558ef59e9Ff90E766E22E480390`                                                     | Ethereum   | The original 2017 work issues ERC-20-like IKB units rather than ERC-721 tokens. The established ERC-721 wrapper is `0x80F1Ed6A1Ac694317dC5719dB099a440627D1ea7`; the wrapped collection currently displays approximately **$13.3 million** of OpenSea volume. For an NFT marketplace, supporting the wrapper is substantially cleaner than treating the native fungible receipts as NFTs. ([Sothebys.com][6])                                                                                         |
| **DADA Creeps & Weirdos — 2017 edition**                    | `0x068696A3cf3c4676B65F1c9975dd094260109d02`                                                     | Ethereum   | A heavily modified CryptoPunks/ERC-20-style contract supporting editions and early on-chain resale royalties. DADA explicitly explains that the contract cannot simply trade through OpenSea because each such legacy contract requires custom logic. The collection has strong institutional provenance, including a reported **500 ETH purchase of the complete 2017 set**. A separate 2019 ERC-721 edition exists, but it is not a simple one-to-one wrapper for the 2017 assets. ([Etherscan][7]) |
